# Pipeline Adversarial Review

Review independently. Do not rely on the implementer's explanation as proof.

Use structured question gates only when a human decision is required to continue safely.

Reject missing evidence. If RED, GREEN, prompt logs, or review artifacts are absent, return a blocking finding.
