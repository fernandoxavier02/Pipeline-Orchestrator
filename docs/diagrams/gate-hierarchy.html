Gate Registry

22 gates. 4 hardness classes.

Every phase transition crosses at least one gate. Gates are not ceremonial checkboxes — each has a defined hardness that determines whether it blocks, asks, or merely advises.

Hardness taxonomy

MANDATORY · 3
Never bypass

Cannot be skipped even with --hotfix. Failure halts the pipeline and reports to the user. Examples: SSOT_CONFLICT, ADVERSARIAL_GATE_MANDATORY for auth/crypto.

HARD · 11
Blocks until resolved

Pipeline stops at the gate. User must answer or the issue must be fixed before continuing. No quiet skips — every block is logged.

CIRCUIT_BREAKER · 3
N strikes & halt

After N consecutive failures or attempts (typically 2-3), pipeline halts and requires manual intervention. Prevents infinite loops.

SOFT · 5
Asks & logs

Recommended but skippable. Every skip is logged with a confidence penalty. Operators can override; the audit trail records each decision.

The 22 gates

Hardness in action

MANDATORY example: SSOT_CONFLICT

Detected by task-orchestrator in Phase 0a when two sources of truth diverge (e.g., spec says "API returns array" but code returns object). Pipeline halts immediately. No --hotfix can bypass. The conflict must be resolved before any other phase runs.

HARD example: TDD_APPROVAL

quality-gate-router emits a GATE_REQUEST v1 per acceptance criterion with the test scenario in plain language. You approve / change / skip per scenario. Implementation cannot begin until all scenarios are approved. Approved scenarios become RED-phase tests in pre-tester.

CIRCUIT_BREAKER example: FIX_LOOP_EXHAUSTED

executor-fix tries to address adversarial findings. If after 3 attempts the reviewers still report CRITICAL/HIGH issues, the gate fires and the pipeline halts with a summary of what didn't converge. Prevents infinite loops on intractable problems.

SOFT example: STALE_CONTEXT

On /pipeline continue, if the saved state is older than 24h, this gate fires. By default it asks the user (revalidate vs. proceed). Escalates to HARD if complexity is COMPLEXA and a sensitive domain (core-flow, auth, data-model) is touched — no waiver possible.
