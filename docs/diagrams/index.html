Pipeline Orchestrator · v6.0.0 · 2026-05-15

End-to-end execution governance for Claude Code.

Pipeline Orchestrator sits between your plan and your production code. It enforces TDD, runs adversarial review with three independent reviewers in parallel, gates every phase transition, and produces a glass-box audit trail you can attach to a PR.

Install

Pipeline Orchestrator is distributed through the FX-Studio-AI marketplace for Claude Code.

# In Claude Code
/plugin marketplace add fernandoxavier02/Pipeline-Orchestrator
/plugin install pipeline-orchestrator

After install you get six top-level commands: /pipeline-orchestrator:pipeline, /pipeline-orchestrator:brainstorm, plus the four mode variants discussed in the overview.
