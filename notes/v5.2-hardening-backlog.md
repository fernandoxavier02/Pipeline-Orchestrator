# v5.2 Hardening Backlog (deferred from Batch 1 review of v5.1.0)

These are real but non-blocking findings deferred to a future hardening pass.

## RunManifest

- **SRP violation**: schema validation + YAML serializer + YAML parser in one class. Extract `RunManifestCodec` (or pair `ManifestSerializer`/`ManifestParser`) when schema evolves to v2.
- **Missing `equals(other)` method**: incomplete value-object contract. Add when first need arises.
- **Shallow Object.freeze**: future schema additions with object/array fields would silently break immutability. Document constraint or deep-freeze.
- **`fromYaml` is not a real YAML parser**: only inverse of `toYaml`. Hand-edits using `~` for null, anchors, multi-line scalars, etc., will misparse.
- **Type coercion in fromYaml**: numeric-looking strings become integers. Schema-aware decoding when codec is extracted.

## RunDirectory

- **`allocate` is Transaction Script, not aggregate factory**: 6 responsibilities in one static. Extract instance methods (`markPhase`, `persist`) and inject `now`/`manifestFactory` for testability.
- **Not transactional**: mkdir + writeFile failure leaves orphan dirs. Wrap in try/catch + cleanup.
- **Concurrent `allocate` race**: two processes can collide on same NNN. Add lockfile or atomic counter.
- **4-digit run number breaks regex**: at run 1000, `/^\d{3}-/` stops matching. Change to `/^\d{3,}-/`.
- **Process-kill orphan**: kill mid-allocate leaves partial dir. Use `.allocating` sentinel.

## PathRewriter

- **Uppercase / digit placeholders**: `<MyFeature>` and `<spec1>` not matched. Add `i` flag and digits to character class if Kiro ever ships such templates.
- **Nested `.kiro/` paths**: `.kiro/specs/<x>/.kiro/specs/<y>/` collapses both into the same target. Defensive test.

## KiroSkillCloner

- **Application Service vs Domain Service**: technically an adapter for a file format. Document the classification; not a refactor.
- **No `cloneAll(specs)` batch API**: Batch 2 will work around with a loop, but a batch API would be more ergonomic.
- **No idempotency contract**: re-cloning already-cloned output is undefined behavior. Add explicit doc + test.

## RunDirectory + slug

- **Emoji-only and stop-words-only prompts collide on slug='run'**: collision resolver handles via `-2`/`-3` suffix, but `001-run`, `002-run-2`, `003-run-3` is confusing. Consider hash fallback for the empty-slug case.
- **Large prompt allocation amplification**: NFKD on a >50KB prompt allocates a big string, then 2 regex passes scan it. Add `prompt.length > 4096` guard.
